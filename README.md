# 獅子巡行 打ち上げ出席管理

皇大神社の獅子巡行、練習後の打ち上げ（居酒屋「カリスマ」ほか）の
**出席と集金を、幹事ひとりで管理するためのアプリ**です。
iPhone と Mac のどちらから入力しても、同じ最新データが見られます。

- 一人あたりの負担金は既定 **¥2,000**（開催日ごとに変更できます）
- 元にした資料：`04_カリスマリスト.xlsx`（人×日付のマトリクス）

---

## ファイルの構成

| ファイル | 何をするもの |
|---|---|
| `index.html` | アプリ本体。これ1枚で画面と操作が全部入っています |
| `Code.gs` | Googleスプレッドシートを読み書きする「受付係」（Apps Scriptに貼るコード） |
| `SETUP.md` | **初回セットアップ手順書。まずこれを読んでください** |
| `README.md` | この説明書（使い方・バックアップ方法） |

## しくみ

```
 iPhone(Safari) ─┐
                 ├─→ index.html（GitHub Pagesなどに置く）
 Mac(Chrome)   ─┘        │
                         ↓ 合言葉つきで読み書き
                  Apps Script（Code.gs）
                         ↓
                  Googleスプレッドシート ← データの本体はここ
```

- データの本当の置き場所は **Googleスプレッドシート**です。人が直接開いても読めます。
- 起動すると、まず端末に残しておいた前回の内容を即表示し、裏で最新に差し替えます（待たされません）。
- 変更のたびに自動保存されます（連打しても0.8秒後にまとめて1回）。**保存ボタンはありません。**
- 圏外でも閲覧・入力はできます。電波が戻ると自動で保存されます。

## 画面の使い方

下の4つのタブで切り替えます。

### ▦ 一覧（メイン）
人×日付の表です。左端に **№（何人目か）** が出ます。

| 操作 | 結果 |
|---|---|
| セルを**タップ** | 参加 ⇄ 不参加 |
| セルを**長押し**（約0.5秒） | 集金済 ⇄ 未集金 |
| セル右下の **¥ / 済** をタップ | 同上（長押しが面倒なとき） |
| セルを**右クリック**（Mac） | 集金済 ⇄ 未集金 |

| 色 | 意味 |
|---|---|
| 緑＋✓ | 参加・**集金済** |
| 黄＋✓ | 参加・**未集金**（要注意） |
| 空欄 | 不参加 |

- 氏名の列と日付の行は、スクロールしても常に見えます。
- 一番下の合計行に、その日の参加人数と金額が出ます。
- **↩︎ 戻す** … 直前の1操作を取り消します（Macは `Command + Z` でも可）
- **絞り込み** … 押すと「未集金の人だけ」「退会者も表示」「日で絞る」「日付の並び順」「印刷」が開きます。
  普段は閉じておくことで、表を広く使えます。条件が効いているときはボタンが緑色になり、
  効いている条件の数が出ます（例：`絞り込み 1 ▴`）
- 氏名検索はいつでも使えます
- **印刷** … 絞り込みの中にあります。A4横向きに整えた表を印刷します

### 📋 日別（居酒屋での会計・集金用）
1日を選ぶと、その日の**参加者名簿と集金チェックリスト**が大きく出ます。
名前を押すだけで集金済になり、「あと何人・いくら」が上に出ます。
不参加の人を押せば、その場で参加に追加できます。

### 📊 集計
会場別・開催日別・個人別の集計が自動で出ます（参加率、集金済、未集金つき）。

### ⚙︎ 管理
開催日の追加・編集・削除、メンバーの追加・編集・削除・退会扱い、
まとめて追加、並べ替え、データの持ち出し／取り込み、各種設定。

## 覚えておくと便利なこと

**退会した人は「削除」ではなく「退会扱い」にする**
管理タブ →その人の「編集」→ **「有効」のチェックを外す**。
過去の参加記録と金額が残ったまま、一覧から隠れます。
「削除」を選ぶとその人の記録も一緒に消えます。

**メンバーをまとめて増やす**
管理タブ →「まとめて追加」→ 1行に1人ずつ入力。
`氏名,ふりがな,区分` のように読点で区切ると、ふりがなと区分も一緒に登録できます。

**ふりがなは最初は空です**
実際の読み方を勝手に決めると間違えるため、あえて空にしてあります。
「ふりがな順」で並べたい場合は、管理タブから各自のふりがなを入れてください
（未入力のままでも、氏名の五十音でだいたい並びます）。

**日付ごとに金額を変えられる**
管理タブ →その日の「編集」→「一人負担金」。
会場が違う日（カリスマ以外）も、会場名を変えれば集計タブで会場別に出ます。

**「学生」が11人いる件**
既存のExcelでは全員「学生」でしたが、それだと集金時に見分けがつかないため、
アプリでは **学生1〜学生11** としています。実名が分かれば管理タブで書き換えてください。

## 他の人に渡す

渡し方は「相手に何をしてほしいか」で3つに分かれます。

### ① 結果だけ配る（作業ゼロ）
- **管理タブ →「Excel(.xlsx)」** … LINEやメールで送れます
- **一覧タブ →「絞り込み」→「印刷」** … A4横。当日配る用
- **日別タブをスクリーンショット** … その日の参加者と集金額だけ共有したいとき

### ② 今の状況を見せる
**方法A：スプレッドシートを閲覧権限で共有する（いちばん手軽）**
スプレッドシート右上の「共有」→ 相手のメールアドレス → 権限を **「閲覧者」** にして送信。
`マトリクス表示` シートで人×日付の表が常に最新で見られます。
アプリのURLも合言葉も渡さずに済みます。

**方法B：アプリを「見るだけ」で使ってもらう**
アプリのURLと **見る用の合言葉**（`Code.gs` の `VIEW_TOKEN`）を渡します。
相手の画面では上部に「閲覧専用モードです」と出て、次のようになります。

- セルを押しても参加/集金は切り替わらない
- 「元に戻す」「開催日の管理」「メンバーの管理」「設定」「危険な操作」は表示されない
- 日別画面の集金チェックと参加者追加も使えない
- Excel・CSV・JSONの**書き出しだけ**はできます

**書き換えられる心配はありません。** アプリ側で隠しているだけでなく、
サーバー側（`Code.gs`）が見る用の合言葉での保存そのものを拒否します。

### ③ 一緒に入力してもらう
アプリのURLと **記録用の合言葉** を渡せば、二人以上で同時に使えます。

同時に触っても大丈夫なように、**保存前に他の人の更新を確認して取り込む**しくみが入っています。

- 相手が保存したあとに自分が保存すると、画面に「他の端末の変更を取り込みました」と出ます
- **自分が触っていないセルは相手の内容がそのまま残り、自分が触ったセルだけが反映されます**
- 打ち上げの席で二人が手分けして集金チェックを入れても、片方の入力が消えることはありません
- 画面を切り替えて戻ってくると、自動で最新を取り込みます

> ただし**同じ人の同じ日**を二人が同時に別々に切り替えた場合は、あとから保存したほうが残ります。
> ここだけは声を掛け合ってください。

### 渡すときの注意
- **記録用の合言葉を渡した相手は、全部を消すこともできます。** 信頼できる方にだけ渡してください
- 合言葉を変えたくなったら、`Code.gs` を書き換えて**デプロイし直し**、各自に入れ直してもらいます
- アプリのURLだけを知られても、合言葉が無ければ中身は見えません

## バックアップの方法

データは常にGoogleスプレッドシートに入っているので、それ自体がバックアップです。
そのうえで、節目には手元にも残しておくと安心です。

**方法1：JSONバックアップ（いちばん確実。全部を復元できます）**
管理タブ →「JSONバックアップ」→ ファイルがダウンロードされます。
戻すときは 管理タブ →「JSONを読み込む」。

**方法2：Excel(.xlsx) で残す（人が見る用）**
管理タブ →「Excel(.xlsx)」。
既存の `04_カリスマリスト.xlsx` と同じ「人×日付」の形に加えて、
「開催日別」「個人別」のシートも付きます。

**方法3：スプレッドシートのコピー**
スプレッドシートで「ファイル」→「コピーを作成」。

**おすすめの頻度**
- 巡行のシーズンが終わったら1回（JSON と Excel の両方）
- 大きく直す前（全消去や一括取り込みの前）に1回

**既存Excelの取り込み**
管理タブ →「Excelを読み込む」で `04_カリスマリスト.xlsx` を選べます。
1行目付近の「氏名」の見出しと、日付として読める列を自動で探します。
セルに `○` があれば集金済、それ以外の何か（`△`、`1`、`✓` など）があれば参加・未集金として読みます。
**取り込むと今のデータは置き換わります**（確認ダイアログが出ます）。

## つながらないときは

「管理」タブ → 接続先（クラウド保存）→ **「接続をテストする」** を押してください。
どこが悪いのかを日本語で表示します。

- **「合言葉が一致しません」** … Googleまでは届いています。`Code.gs` の
  `var TOKEN = '……';` の文字をそのままコピーして貼り付けてください。
  入力中の合言葉の文字数と先頭・末尾の文字も表示されるので、見比べれば違いが分かります
- **「Googleまで届いていません」** … デプロイの「アクセスできるユーザー＝全員」と、
  URLの末尾が `/exec` かを確認してください

## 気をつけること

- **`Code.gs` を書き換えたときは、必ず「デプロイ」→「デプロイを管理」→ 鉛筆マーク →
  バージョン「新バージョン」→「デプロイ」まで行ってください。** 保存だけでは反映されません。
- **このアプリのファイルには名簿を持たせていません。** 公開URLを知られても
  参加者の氏名が読まれないようにするためです。名簿はスプレッドシート側にあります。
- 合言葉は `index.html` に書かず、端末ごとに画面から入力する運用にしています
  （`index.html` を一般公開すると、中に書いた文字列は誰でも読めるためです）。
- 同時に複数の端末で編集しても、変更は自動で突き合わせて取り込まれます（上の「③一緒に入力してもらう」参照）。
- スプレッドシートの `マトリクス表示` シートは、保存のたびに自動で作り直されます。
  **そこを直接書き換えてもアプリには反映されません。** 直接直したいときは
  `メンバー` `開催日` `出席記録` の各シートを編集し、アプリで「最新を取得」を押してください。

## 動作を確認した環境

- Chrome（Mac）で、49名 × 11日 = 539セルの表で確認
  - セルのタップ／長押し、スクロール中の氏名列・日付行・合計行の固定
  - 既存 `04_カリスマリスト.xlsx` の取り込み（49名・11日を自動検出）
  - Excel／CSV／JSONの書き出し、JSONの往復
  - 1手の取り消し、ドラッグでの並べ替え、ダークモード
- 同時編集を模擬サーバーで検証
  - 端末Aが保存 → 端末Bが別のセルを保存 → 3件すべてが残り、消えたものはゼロ
  - 見る用の合言葉ではサーバーが保存を拒否し、スプレッドシートの更新回数が変わらないこと
- iPhone相当（375×812）の画面幅で、入力欄・ダイアログ・表の見え方を確認
  - 文字入力時にページが勝手に拡大しないこと（入力欄を16pxにして対処）
  - 追加・編集の画面が画面下からせり上がり、見出しとボタンが常に見えること
