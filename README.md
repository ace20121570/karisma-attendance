# 獅子巡行 打ち上げ出席管理

皇大神社の獅子巡行、練習後の打ち上げ（居酒屋「カリスマ」ほか）の
**出席と集金を、幹事ひとりで管理するためのアプリ**です。
iPhone と Mac のどちらから入力しても、同じ最新データが見られます。

- 一人あたりの負担金は既定 **¥2,000**（開催日ごとに変更できます）
- 元にした資料：`04_カリスマリスト.xlsx`（人×日付のマトリクス）

---

## しくみ

```
 iPhone(Safari) ─┐
                 ├─→ index.html（GitHub Pagesなどに置く）
 Mac(Chrome)   ─┘        │
                         ↓ 合言葉つきで読み書き
                  Apps Script（Code.gs）
                         ↓
                  Googleスプレッドシート ← データの本体はここ
```

- データの本当の置き場所は **Googleスプレッドシート**です。人が直接開いても読めます。
- 起動すると、まず端末に残しておいた前回の内容を即表示し、裏で最新に差し替えます（待たされません）。
- 変更のたびに自動保存されます（連打しても0.8秒後にまとめて1回）。**保存ボタンはありません。**
- 圏外でも閲覧・入力はできます。電波が戻ると自動で保存されます。

## 画面の使い方

下の4つのタブで切り替えます。

### ▦ 一覧（メイン）
人×日付の表です。

| 操作 | 結果 |
|---|---|
| セルを**タップ** | 参加 ⇄ 不参加 |
| セルを**長押し**（約0.5秒） | 集金済 ⇄ 未集金 |
| セル右下の **¥ / 済** をタップ | 同上（長押しが面倒なとき） |
| セルを**右クリック**（Mac） | 集金済 ⇄ 未集金 |

| 色 | 意味 |
|---|---|
| 緑＋✓ | 参加・**集金済** |
| 黄＋✓ | 参加・**未集金**（要注意） |
| 空欄 | 不参加 |

- 氏名の列と日付の行は、スクロールしても常に見えます。
- 一番下の合計行に、その日の参加人数と金額が出ます。
- **↩︎ 戻す** … 直前の1操作を取り消します（Macは `Command + Z` でも可）
- 氏名検索、「未集金の人だけ」「退会者も表示」「日で絞る」で絞り込めます
- **印刷** … A4横向きに整えた表を印刷します

### 📋 日別（居酒屋での会計・集金用）
1日を選ぶと、その日の**参加者名簿と集金チェックリスト**が大きく出ます。
名前を押すだけで集金済になり、「あと何人・いくら」が上に出ます。
不参加の人を押せば、その場で参加に追加できます。

### 📊 集計
会場別・開催日別・個人別の集計が自動で出ます（参加率、集金済、未集金つき）。

### ⚙︎ 管理
開催日の追加・編集・削除、メンバーの追加・編集・削除・退会扱い、
まとめて追加、並べ替え、データの持ち出し／取り込み、各種設定。

## 覚えておくと便利なこと

**退会した人は「削除」ではなく「退会扱い」にする**
管理タブ →その人の「編集」→ **「有効」のチェックを外す**。
過去の参加記録と金額が残ったまま、一覧から隠れます。
「削除」を選ぶとその人の記録も一緒に消えます。

**メンバーをまとめて増やす**
管理タブ →「まとめて追加」→ 1行に1人ずつ入力。
`氏名,ふりがな,区分` のように読点で区切ると、ふりがなと区分も一緒に登録できます。

**ふりがなは最初は空です**
実際の読み方を勝手に決めると間違えるため、あえて空にしてあります。
「ふりがな順」で並べたい場合は、管理タブから各自のふりがなを入れてください
（未入力のままでも、氏名の五十音でだいたい並びます）。

**日付ごとに金額を変えられる**
管理タブ →その日の「編集」→「一人負担金」。
会場が違う日（カリスマ以外）も、会場名を変えれば集計タブで会場別に出ます。

**「学生」が11人いる件**
既存のExcelでは全員「学生」でしたが、それだと集金時に見分けがつかないため、
アプリでは **学生1〜学生11** としています。実名が分かれば管理タブで書き換えてください。

## バックアップの方法

データは常にGoogleスプレッドシートに入っているので、それ自体がバックアップです。
そのうえで、節目には手元にも残しておくと安心です。

**方法1：JSONバックアップ（いちばん確実。全部を復元できます）**
管理タブ →「JSONバックアップ」→ ファイルがダウンロードされます。
戻すときは 管理タブ →「JSONを読み込む」。

**方法2：Excel(.xlsx) で残す（人が見る用）**
管理タブ →「Excel(.xlsx)」。
既存の `04_カリスマリスト.xlsx` と同じ「人×日付」の形に加えて、
「開催日別」「個人別」のシートも付きます。

**方法3：スプレッドシートのコピー**
スプレッドシートで「ファイル」→「コピーを作成」。

**おすすめの頻度**
- 巡行のシーズンが終わったら1回（JSON と Excel の両方）
- 大きく直す前（全消去や一括取り込みの前）に1回

**既存Excelの取り込み**
管理タブ →「Excelを読み込む」で `04_カリスマリスト.xlsx` を選べます。
1行目付近の「氏名」の見出しと、日付として読める列を自動で探します。
セルに `○` があれば集金済、それ以外の何か（`△`、`1`、`✓` など）があれば参加・未集金として読みます。
**取り込むと今のデータは置き換わります**（確認ダイアログが出ます）。

## 気をつけること

- **`Code.gs` を書き換えたときは、必ず「デプロイ」→「デプロイを管理」→ 鉛筆マーク →
  バージョン「新バージョン」→「デプロイ」まで行ってください。** 保存だけでは反映されません。
- 合言葉は `index.html` に書かず、端末ごとに画面から入力する運用にしています
  （`index.html` を一般公開すると、中に書いた文字列は誰でも読めるためです）。
- 幹事おひとりで使う前提のため、同時に2台で編集した場合は**あとから保存したほうが残ります**。
- スプレッドシートの `マトリクス表示` シートは、保存のたびに自動で作り直されます。
  **そこを直接書き換えてもアプリには反映されません。** 直接直したいときは
  `メンバー` `開催日` `出席記録` の各シートを編集し、アプリで「最新を取得」を押してください。
